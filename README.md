# zyb.cxayg.studio

Static GitHub Pages site for `zyb.cxayg.studio`.

The published files live in `site/`. Pushes to `main` deploy through GitHub Actions.

## Custom domain

The repository Pages settings use `zyb.cxayg.studio` as the custom domain.

In Cloudflare DNS, point `zyb` to:

```text
zgyzgd1.github.io
```
